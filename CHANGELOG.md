# Изменения перевода

## Лаунчер 0.22 — 2026-09-16

Добавлена поддержка **Steam build 25251167**. Исправлена остановка с сообщением «Версия или состояние файла не поддерживается: F1_25.exe» для этой проверенной сборки. Неизвестные файлы по-прежнему отклоняются.

**Для этого исправления скачайте полный архив лаунчера 0.22 и распакуйте в новую папку.** Кнопка «Обновить перевод» в 0.21 обновляет только текст и не устанавливает новый код лаунчера. Закройте игру и старый лаунчер, откройте новый `Launcher.exe`, укажите папку игры, нажмите «Проверить файлы», затем «Установить перевод».

Текст остаётся **0.15.5**. EXE игры и античит не меняются. Старые резервные копии `.f1ru-v10` сохраняются; для новой сборки используются `.f1ru-v10-build25251167`, чтобы восстановление не возвращало старый game.dat.

На изолированной копии проверены перенос после обновления Steam, установка, повторная установка, откат к оригиналу новой сборки и отказ для неизвестных файлов. Установленная локально адаптация прошла проверку файлов; запуск в игре после адаптации пока не подтверждён.



## 0.15.5 — 2026-09-16

- Добавлены готовые авторские правки 30 000–56 134; совокупное покрытие присланными правками: **10 000–56 134 — 46 135 записей без пропусков**.
- По сравнению с публичной 0.15.3 изменены **22154** записи. Формулировки автора сохранены.
- Проверены нумерация, стыки, служебные метки, ключи, UTF-8, контрольные суммы, установка, обновление и возврат оригинала на изолированной копии.
- Лаунчер остаётся **0.21**: **Обновления → Проверить обновления → Обновить перевод**. Повторно скачивать лаунчер не нужно.
- Для первой установки скачайте ZIP ниже и распакуйте целиком. Основа — японский языковой пакет Steam; перед установкой закройте игру.
- Переводит текст и субтитры; голоса остаются оригинальными. Это не повторная ручная смысловая вычитка всех 56 134 записей и не проверка совместимости онлайна.
