F1 25 на русском — релиз 0.33, внутренняя версия лаунчера 0.33.1
Автор и разработчик: Karsvein

Один файл: F1_25_RU_v0.33.exe. Python пользователю не нужен.
Исправление 0.33.1 от 2026-11-07 обновляет существующий релиз v0.33 без нового релиза:
https://github.com/kasyanovea17-crypto/F1-25-Russian/releases/tag/v0.33

Закройте игру, выберите найденную папку, проверьте совместимость и установите текстовый перевод. Варианты: русский полностью либо русский с оригинальными именами пилотов, команд и трасс.

ОЗВУЧКА НА ВЫБОР
«Озвучка» → «Голос инженера»: английский оригинал или русский тестовый набор 1596 аудиофрагментов. Нажмите «Применить» при закрытой игре. Модуль рассчитан на проверенные английские аудиобанки F1 25 1.26. Язык клиента должен быть English. Текстовый перевод и голос Макса выбираются отдельно.
Короткие числа 5/7/9 и префикс среднего времени ещё требуют прослушивания. Все игровые ветви и прерывания реплик в гонке не объявляются проверенными.

Русский голос Макса 192 реплики — отдельный тест. Голосовые команды доступны отдельной кнопкой; в гонке удерживайте T (русская Е).

HOTFIX 0.33.1 — 2026-11-07
Модуль голоса инженера определяет игру по точным именам процессов F1_25 и F1_25_dx12: лаунчер больше не вызывает ложную блокировку. Кнопка показывает «Уже установлено» для текущего голоса или «Закройте игру» при запущенной игре. Проверка прав использует встроенную роль Windows Administrator и не зависит от языка системы. Подтверждение UAC, блокировка изменений при запущенной игре, контрольные суммы и резервные копии сохранены.

ИСПРАВЛЕНИЯ 0.33
Неполный кэш восстанавливается без перезаписи существующих файлов. Добавлен один проверенный компонент EA для профиля Steam 1.26. Ошибки доступа, занятого файла и политики запуска получили пояснения. Подписи, контрольные суммы и проверки неизвестных файлов сохранены. Антивирус не отключается, исключения не добавляются.

Сохраняйте резервные папки и журналы. Текст, инженер, Макс и голосовые команды имеют отдельное восстановление. Для неизвестной структуры ресурсов потребуется отдельный профиль совместимости.
