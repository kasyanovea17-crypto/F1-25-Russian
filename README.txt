# Лаунчер 0.28 — выбор перевода

На вкладке «Установка» доступны два варианта:
- **Русский перевод** — текущий текст 0.15.5 без изменений.
- **Русский + имена на английском** — та же база 0.15.5, но имена пилотов и персонажей, команды, трассы и модели по английскому оригиналу.

Сначала выберите вариант и язык озвучки, затем подтвердите, что игра закрыта, проверьте совместимость и нажмите «Установить перевод». Выбор сохраняется между запусками. Для смены варианта удалять перевод не требуется: повторите проверку и установку. Английская/японская озвучка выбирается независимо.

Кнопка обновления текста относится к обычной русской версии. Вариант с оригинальными именами обновляется полным архивом лаунчера из Releases; при его выборе обычное обновление отключено, чтобы случайно не заменить вариант.

Оба варианта имеют 56 134 записи. EXE, античит и исходные шрифты этим обновлением не меняются; сохраняется прежний движок установки и профили Steam/EA. Проверки выполнялись на копиях; запуск реальной игры в рамках выпуска не выполнялся.

F1 25 — русский текст и субтитры
Лаунчер 0.28 / текст 0.15.5 / Steam и экспериментальная поддержка EA app

Для проверки EA-сборки с F1_25.exe версии 1.0.141.7865 из полученного отчёта.
Сохранён прежний профиль Steam. Другие версии проверяются по индексу и
ресурсам: изменение структуры требует отдельной адаптации, а не отключения проверки.

УСТАНОВКА
1. Распакуйте весь архив в отдельную папку, не в папку игры.
2. EA app → Библиотека → F1 25 → Управление → Свойства → Язык.
   Выберите English или Japanese и дождитесь загрузки файлов.
   В Steam: F1 25 → Свойства → Общие → Язык.
3. Полностью закройте игру. Откройте Launcher.exe из распакованной папки.
4. Укажите папку установленной игры (например, D:\F1 25).
5. В разделе «Озвучка» выберите тот же язык. Этот выбор сам по себе
   не переключает язык клиента. Для EA язык подтверждается пользователем.
6. «Установка» → выберите вариант перевода → отметьте «Язык выбран, игра закрыта» →
   «Проверить совместимость» → «Установить перевод».
7. Запустите игру через EA app или Steam; проверьте меню, карьеру,
   радио/комментарии и подключение к сети.

ПРОВЕРЕНО
Движок: 175 проверок переключения переводов Steam/EA, повторной установки,
отката и отказа при повреждённом тексте. Интерфейс: 92 проверки.
Обновление текста: 197 проверок.
Запуск EA-игры и онлайн на пользовательском ПК пока не проверены.
Исходные EXE, античит, штатные шрифты и озвучка не редактируются.
Добавляются два русских шрифтовых пакета и два LNG-файла.
В game.dat меняются маршруты локализации и шрифтов; его оригинал сохраняется.

ОТКАТ
В лаунчере выберите «Вернуть оригинал» либо запустите «Вернуть оригинал.cmd».
Для автоматизации также приложен Python-скрипт ROLLBACK.sh:
  python ROLLBACK.sh "D:\F1 25"
Он вызывает тот же проверяемый движок восстановления.
Резервные копии не удаляйте до завершения проверки.

Полный архив выпускается в GitHub Releases (v0.28). Автоматическое обновление
текста не заменяет сам лаунчер и не загружает новые профили совместимости.
