# Лаунчер 0.28 — выбор перевода

На вкладке «Установка» доступны два варианта:
- **Русский перевод** — текущий текст 0.15.5 без изменений.
- **Русский + имена на английском** — та же база 0.15.5, но имена пилотов и персонажей, команды, трассы и модели по английскому оригиналу.

Сначала выберите вариант и язык озвучки, затем подтвердите, что игра закрыта, проверьте совместимость и нажмите «Установить перевод». Выбор сохраняется между запусками. Для смены варианта удалять перевод не требуется: повторите проверку и установку. Английская/японская озвучка выбирается независимо.

Кнопка обновления текста относится к обычной русской версии. Вариант с оригинальными именами обновляется полным архивом лаунчера из Releases; при его выборе обычное обновление отключено, чтобы случайно не заменить вариант.

Оба варианта имеют 56 134 записи. EXE, античит и исходные шрифты этим обновлением не меняются; сохраняется прежний движок установки и профили Steam/EA. Проверки выполнялись на копиях; запуск реальной игры в рамках выпуска не выполнялся.

# F1 25 — русский текст и субтитры

**Karsvein · Лаунчер 0.28 · Текст 0.15.5 · Steam и EA app**

[Скачать общий лаунчер 0.28](https://github.com/kasyanovea17-crypto/F1-25-Russian/releases/tag/v0.28) · [Руководство в Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3800786076)

## Что изменилось
- Один лаунчер для Steam и EA app. Прежний профиль Steam сохранён; для EA добавлен отдельный профиль ресурсов.
- Инструкции по выбору английской или японской озвучки в обоих клиентах. Выбор в лаунчере сохраняет предпочтение, но не скачивает голоса и не переключает язык клиента.
- Русский текст и отдельные шрифты для английской и японской основы. Штатные шрифты, EXE, античит и голосовые банки не редактируются.
- Проверка совместимых микрообновлений сохранена. Изменения необходимых ресурсов по-прежнему останавливают установку.

**EA app: экспериментальная поддержка сборки с EXE 1.0.141.7865.** Установка и откат проверены на копиях файлов. Запуск игры, все сцены, озвучка и онлайн на EA-ПК ещё требуют проверки игроком. Профиль Steam build 25251167 сохранён без изменения.

## Установка / обновление
1. Закройте игру и старый лаунчер. Скачайте `F1_25_RU_v0.28_text0.15.5.zip` из Assets и распакуйте **весь архив в новую папку**.
2. Выберите язык игры:
   - **Steam:** F1 25 → Свойства → Общие → Язык → English либо Japanese.
   - **EA app:** Библиотека → F1 25 → Управление → Свойства → Язык → English либо Japanese.
3. Дождитесь загрузки файлов клиента. В лаунчере укажите настоящую папку F1 25 и тот же язык на вкладке «Озвучка».
4. «Установка» → выберите вариант перевода → подтвердите подготовку → «Проверить совместимость» → «Установить перевод».
5. Запускайте игру через свой клиент. В настройках аудио отдельно проверьте язык радио и комментариев.

**Японский язык не обязателен. Это русский текст, а не русская озвучка.**

**Старый лаунчер обновляет кнопкой только текст. Для выбора перевода скачайте полный архив 0.28.** Текст остаётся 0.15.5.

## Проверки
175 проверок движка, 92 проверки интерфейса и 197 проверок обновления. Переключение между переводами Steam/EA, повторная установка, откат и отказ при повреждённом тексте. [Подробности](TEST_REPORT.md).

Новые сборки игры проверяются по ресурсам и индексу. Совместимость со всеми будущими обновлениями не обещается; проверки не отключены.

## Вернуть оригинал
Закройте игру → «Вернуть оригинал». Либо используйте `Вернуть оригинал.cmd`.
Резервные копии и журнал незавершённой операции сохраняйте до завершения проверки.
`ROLLBACK.sh` — дополнительная Python-обёртка того же движка: `python ROLLBACK.sh "D:\F1 25"`.

## Обновления текста
«Обновления» загружает текст из этого репозитория, сверяет SHA-256, размер, версию и структуру LNG. Код лаунчера, шрифты и профили совместимости этим каналом не обновляются. Учётная запись GitHub игроку не нужна.

## Сборка из исходников
Windows, .NET Framework 4.x, Windows PowerShell 5.1:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `dist/F1_25_RU_v0.28_text0.15.5.zip`. Проверяются хеши payload и 92 UI self-tests. Скрипт отказывается перезаписывать существующий результат.

`Compatibility.cs` поставляется рядом с `Engine.ps1`. Старые `payload/config.patch` и `payload/fonts_japanese.erp` оставлены в истории репозитория, в текущий архив не включаются.

Для следующего текста: отредактируйте `translations.json`, сохранив ключи и метки, запустите `python release_text.py НОВАЯ_ВЕРСИЯ "Описание"`; публикуйте новый пакет вместе с `updates/stable.json`. Старые пакеты не перезаписывайте. Затем пересоберите оригинальные имена на новой базе: `python build_original_names.py PATH_TO_ORIGINAL_ENGLISH_LNG`. Проверьте список изменений; `original_names_rules.json` содержит правила имён, а не старый русский перевод.

`IntegrationTests.cs` — исторический тест прежнего установщика; актуальные результаты описаны в `TEST_REPORT.md`.
