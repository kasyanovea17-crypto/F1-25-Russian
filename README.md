# F1 25 на русском

Русский текст и субтитры, отдельные шрифты, голосовые команды и тестовая озвучка Макса. Автор и разработчик — **Karsvein**.

## Скачать

**[Лаунчер 0.32 — один EXE](https://github.com/kasyanovea17-crypto/F1-25-Russian/releases/tag/v0.32)**

Скачайте `F1_25_RU_v0.32.exe` и запустите. Пользователю не нужны Python или отдельная распаковка. Встроенные файлы извлекаются в пользовательский кэш и проверяются по контрольным суммам. SHA-256 опубликован рядом с EXE.

## Что нового в 0.32

- Новый нативный тёмный интерфейс, верхнее меню, параметры и диалоги операций.
- Автопоиск папки F1 25 в Steam/EA app, сохранение выбранной установки и ручной выбор.
- Исправлено перекрытие строки состояния и кнопки папки.
- Язык озвучки определяется после папки игры; сохранённый выбор пользователя имеет приоритет.
- Tab остаётся в открытом диалоге, Esc возвращает управление главному экрану.
- Ошибка неправильного пути видна непосредственно в параметрах.
- Одиночный EXE сохраняет свой исходный каталог для поиска игры рядом с собой.
- Добавлен отдельный точный профиль и закреплённый перевод для проверенного набора F1 25 1.20.0.

Подробности и оставшиеся проверки — [в описании релиза](releases/v0.32.md).

## Установить перевод

1. Закройте игру и дождитесь загрузки выбранного языка в Steam или EA app.
2. Запустите лаунчер и проверьте автоматически найденную папку. При нескольких установках выберите нужную в параметрах.
3. Выберите русский перевод либо **«Русский + имена на английском»**. Во втором варианте пилоты, команды и трассы сохраняют оригинальные имена.
4. Проверьте совместимость, подтвердите подготовку и установите перевод.
5. Запускайте игру через свой клиент.

Поддерживаются точные профили **1.18, 1.20, 1.24 и 1.26**. Номер версии сам по себе не гарантирует совпадение ресурсов: лаунчер проверяет файлы перед установкой и сохраняет неизвестные наборы без изменения.

Текст для 1.26 — **0.15.6**, вариант с оригинальными именами — **0.15.6.1**. Для 1.20 используется отдельный набор **55 991 строки**, который не обновляется обычным каналом текста 1.26.

Шрифт входит в EXE. Для перевода можно использовать English либо Japanese; японский язык не обязателен. Штатные EXE, античит и оригинальные шрифты установщик не заменяет. Сохранения и резервные копии сохраняются.

## Голосовые команды и озвучка

Откройте **«Озвучка» → «Голосовые команды»**. Для русских команд используется английская база игры; русский текст сохраняется. Компонент Microsoft устанавливается отдельным действием, если отсутствует. В заезде удерживайте **T** (русская **Е**) до открытия радиоменю и произносите показанную фразу. Все команды доступны в отдельной вкладке лаунчера.

**Русский голос Макса** — отдельный тестовый пакет, не автоматическая часть установки текста. Он рассчитан на точно проверенный английский аудиобанк 1.26 и содержит 192 синтетические реплики. 18 записей требуют дополнительного прослушивания. Поддержка текстового профиля 1.20 не означает поддержку голосовых модулей на этой версии; их прежние проверки сохранены.

Текст, голосовые команды и тестовая озвучка имеют отдельные действия восстановления. Перед изменениями закройте игру. Не удаляйте резервные папки `.f1ru-*` и журналы установки.

## Проверки и статус

Автоматические проверки интерфейса, состояния диалогов, автопоиска, профилей, упаковки и отката выполняются на изолированных данных. Обнаружение папки не включает установку и не заменяет проверку совместимости.

Свежая визуальная сверка всех окон и проверка на реальных экранах 125–150% ещё не завершены. Автоматические проверки геометрии не заменяют такую сверку. Для точной сборки 1.20 подтверждены структура ресурсов и установка/откат на копиях; запуск именно этой сборки игры не объявляется проверенным. Озвучка остаётся тестовой.

## Сборка из исходников

Нужны Windows x64, Windows PowerShell, компилятор .NET Framework и Python 3.11 или новее. Пользовательскому EXE Python не требуется.

В свежем checkout выполните:

```powershell
python -B scripts/release_ci_032.py
```

Результат: `dist/F1_25_RU_v0.32.exe`, отчёт `dist/release-ci-result.json`. Сборка использует явный список `.release/package-v0.32.txt`; тестовые файлы и игровые бинарники в EXE не включаются. `build.ps1 -PackageOnly` выполняет только подготовку пакета и базовую проверку, а не полный выпускной набор тестов.

Канал текста `updates/stable.json` отделён от версии лаунчера. Изменения профилей, кода и шрифтов доставляются новым EXE.
