# F1 25 — русский текст и субтитры

**Автор и разработчик: Karsvein.** Неофициальный перевод интерфейса и субтитров; оригинальные голоса сохраняются.

[Скачать лаунчер](https://github.com/kasyanovea17-crypto/F1-25-Russian/releases/latest) · [Руководство в Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3800786076)

## Установка
1. Распакуйте **весь** архив лаунчера в отдельную папку.
2. Steam → Библиотека → F1 25 → Свойства → Общие → Язык: **японский**.
3. Дождитесь загрузки файлов и закройте игру.
4. Запустите `Launcher.exe`, выберите папку игры, подтвердите подготовку.
5. Нажмите **Проверить файлы**, затем **Установить перевод**.
6. Запускайте игру через Steam.

В этой сборке кириллица подготовлена для японского пакета шрифтов. Английский вариант не подтверждён проверкой в игре.

## Обновление без замены лаунчера
Откройте **Обновления → Проверить обновления → Обновить перевод**.
Лаунчер получает только файл русского текста из этого репозитория: сверяет версию, размер, SHA-256, совместимость и структуру 56 134 записей.
Если отмечено **После загрузки установить также в игру**, перевод сразу устанавливается в выбранную папку. Перед этим закройте игру. Без отметки обновляется только пакет в лаунчере.
Программы, скрипты, шрифты и патчи из сети этим механизмом не загружаются. Новая версия самого лаунчера устанавливается отдельно.

При обрыве операции кнопка **Восстановить обновление** возвращает предыдущий пакет; журнал и снимки сохраняются в `.updates`. Сетевой запрос выполняется только по нажатию кнопки, учётная запись GitHub игроку не нужна.

## Возврат оригинала
Закройте игру → **Вернуть оригинал → Восстановить оригинал**. Восстанавливаются исходные `game.dat` и японский шрифт, удаляются два файла русского текста. Резервная копия `.f1ru-v10` и сохранения остаются.
EXE игры и античит лаунчер не изменяет. Восстановление онлайна не гарантируется: совместимость проверяйте отдельно после удаления модификаций.

## Для автора: выпуск следующего перевода
1. Редактируйте значения в `translations.json`, сохраняя ключи, плейсхолдеры и теги.
2. Выполните `python release_text.py 0.15.1 "Описание исправлений"` с **новым** номером версии.
3. Закоммитьте `translations.json`, новую папку `updates/0.15.1` и обновлённый `updates/stable.json` в ветку `main`.
4. Нажмите проверку обновлений в лаунчере. Старые опубликованные версии не перезаписывайте.

Собрать лаунчер на Windows: `powershell -NoProfile -File build.ps1`. Нужен .NET Framework 4.x. Результат — `dist/F1_25_RU_v0.21.zip`.
История Git показывает изменения исходников, JSON-перевода и файлов канала. Тестовые изменённые фразы в опубликованный канал не входят.
