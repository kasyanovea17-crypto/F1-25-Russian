# F1 25 RU 0.33

Скачайте **F1_25_RU_v0.33.exe**. Это один EXE с переводом, шрифтами и необязательными голосовыми модулями. Python и ручная распаковка пользователю не нужны.

## Озвучка на выбор

В «Озвучка» → «Голос инженера» доступны английский оригинал и русский тестовый набор 1596 аудиофрагментов. Изменения применяются только по отдельному действию при закрытой игре. Текст, голос инженера, голос Макса и распознавание команд остаются независимыми.

Инженер рассчитан на проверенные английские аудиобанки 1.26; в клиенте игры выберите English. Переключение сохраняет остальные записи банков. Неизвестные изменения выбранных записей требуют проверки вместо слепой перезаписи.

Это тестовая озвучка радиоменю, а не всей игры. Полный игровой обход событий и прерывания реплик ещё требуют тестов. Произношение коротких чисел 5/7/9 и префикса среднего времени нуждается в прослушивании.

## Исправления запуска

- Исправлен случай неполного кэша с отсутствующим Launcher.exe: недостающие неизменяемые файлы восстанавливаются после проверки комплекта. Изменённые файлы, неизвестные DLL и опасные подмены пути не перезаписываются.
- Для точного профиля Steam 1.26 добавлен один проверенный новый компонент EA. Проверка подписей и неизвестных ревизий сохранена; античит и EXE игры не изменяются.
- Несовпадение профиля больше не выдаётся за ошибку подписи. Ошибки доступа, занятого файла и запрета запуска политикой Windows получают понятные пояснения.

Блокировка программы антивирусом не объявляется устранённой для всех систем. Защита Windows не отключается и исключения не добавляются.

Окна настроек и озвучки выводятся поверх основного интерфейса; нижняя панель не перекрывает подсказки.

## Сохранение данных

Резервные копии и журналы сохраняются. Не удаляйте резервные папки игры. Снятие голосового модуля отдельно от восстановления текста. При неизвестной структуре файлов установщик сохраняет их и останавливает изменение.

Текстовые профили 1.18/1.20/1.24/1.26 сохраняются. Совместимость голосовых модулей с другими профилями и онлайн-совместимость сторонних модов не заявляются.

## Hotfix 0.33.1 — 2026-11-07

Обновление существующего релиза **v0.33**, без нового релиза. Скачиваемый файл по-прежнему называется **F1_25_RU_v0.33.exe**; внутренняя версия лаунчера — **0.33.1**.

- Проверка процессов в модуле голоса инженера сопоставляет только точные имена `F1_25` и `F1_25_dx12`. Лаунчер больше не принимается за запущенную игру.
- Кнопка применения показывает «Уже установлено» для текущего голоса или «Закройте игру», если игра запущена.
- Проверка прав использует встроенную роль `WindowsBuiltInRole.Administrator` и не зависит от языка Windows.

Подтверждение UAC, блокировка изменений при запущенной игре, контрольные суммы и резервные копии сохранены. Исправление не подтверждает прохождение всех игровых ветвей озвучки; такой игровой тест остаётся отдельной проверкой.
