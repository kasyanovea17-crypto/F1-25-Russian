## Один EXE вместо архива

Скачайте **F1_25_RU_v0.31.exe** и запустите. Лаунчер сам извлечёт и проверит встроенные файлы. Python и ручная распаковка не нужны. Системные компоненты Microsoft при необходимости устанавливаются кнопкой в лаунчере.

### Что нового
- Русские голосовые команды совпадают с текстом меню: 37 команд,104 записи,5 контекстов.
- Кнопка обновления прежнего словаря сохраняет исходную резервную копию и восстановление.
- Отдельная опциональная тестовая русская озвучка Макса:192 синтетические реплики. Она не устанавливается автоматически;18 записей отмечены для дополнительного прослушивания.
- Пакет Макса содержит только изменённые данные:2646 остальных звуков берутся из установленного банка.
- Сохранены оба варианта перевода, кириллические шрифты, профили1.18/1.24/1.26 Steam/EA и текстовые обновления.

### Как пользоваться
1. Закройте игру и запустите новый EXE.
2. Укажите папку F1 25, проверьте совместимость, выберите вариант перевода.
3. Для команд: «Озвучка» → «Голосовые команды», база игры English. В заезде удерживайте T/Е и произносите фразу из радиоменю.
4. Для Макса: «Озвучка» → «Русский голос Макса · тест». Поддерживается точно проверенный английский банк1.26; для других банков операция остановится без замены.

### Проверки
Лаунчер, профили, обновления, словарь, delta-пакет и восстановление проверены автоматически. Акустические тесты команд на синтетической русской речи:208/208. Это не проверка любого микрофона или всех игровых действий. Игровое воспроизведение полного пакета Макса остаётся тестовым.

Резервные копии сохраняются отдельно от EXE. Перевод, команды и озвучка имеют отдельное восстановление. Исходные EXE и античит не заменяются.
