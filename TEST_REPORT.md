# Проверка версии 0.30 — 10.10.2026

Проверенная сборка: лаунчер 0.30, текст 1.26 — 0.15.6 / 0.15.6.1, шрифт 08.
Установка в рабочую игру и запуск игры в этой файловой проверке не выполнялись. Сборка для GitHub дополнительно проходит переносимые CI-тесты и проверку упакованного архива перед публикацией.

## Результаты

- UI_TEST_PASS: 108 проверок; интерфейс 0.30 просмотрен в режиме --preview.
- PROFILE_GATE_PASS: 44 проверки. Неподходящая версия блокируется до загрузки текста.
- UPDATE_TEST_PASS: 239 проверок, включая неверный SHA256, повреждённый LNG, откат после сбоя, прерванное обновление и сохранение профилей ресурсов.
- Шрифт: изменена только заглавная У жирного начертания относительно установленного font06. Строчная у, Latin Y/y, остальные глифы, интервалы и кернинг совпадают с font06.
- 174240 проверок соседних кириллических букв: тесных пар не обнаружено при проверенных размерах/фазах.
- Файловая матрица: 1.18, 1.24, 1.26 EA, 1.26 Steam. 74 операций дали ожидаемые результаты; финальные файлы 12 копий повторно сверены по хешам.
- Каждый профиль: установка, смена обоих вариантов, повторная установка, обновление с публичной 0.29, откат на отдельной копии, отказ при неизвестных EXE/DAT/шрифте и чужом наборе текста.
- Дополнительная копия текущей установки: font06 → font08, текст 0.15.5.2 → 0.15.6.1, затем восстановление оригинальных ресурсов. Рабочая игра осталась прежней.
- 24 проверки наличия/отсутствия дополнительных компонентов; их байты сохранены. EXE и защитные компоненты не запускаются и не патчатся.
- История original_names: старый сборщик воспроизводимо стирал previous_sha256; новый сохраняет предыдущие хеши, повторный запуск идемпотентен.
- Два набора 1.18/1.24 сохранены без редакционных изменений.

## Воспроизводимость

Исходники интеграционных проверок находятся в tests/; они используют локальные игровые образцы. Переносимая проверка сборки без игровых образцов — scripts/release_ci.py. Полные команды, входы, stdout/stderr и коды завершения сохранены в evidence/RELEASE_MATRIX.json, PRIVATE06_UPGRADE.json, aux030b/COMMANDS.json, HISTORY_REGRESSION.json и FINAL_COMMANDS.json на машине сборки. Эти журналы и игровые образцы не публикуются.
Матрица выполнена двумя сессиями: старые профили завершены в release030b; после исправления загрузки модуля подписи в тестовом стенде текущие профили завершены в release030c. Код Engine.ps1 при этом не менялся. combine_matrix.py повторно проверяет все конечные состояния.
Архив собирается по явному списку файлов; тестовые игровые бинарники, DAT и личные журналы в него не включаются.
